Status: Measured locally
Scope: M6 hardening baseline

This is a reproducible local measurement, not a production-capacity claim.

- Client concurrency: 4 workers
- Network: loopback (`127.0.0.1`)
- Dataset: no business data; liveness endpoint only
- Command: `npm run load:api`

## Interpretation and limits

The result describes this endpoint under this local workload. It does not represent matching capacity, location-ingestion capacity, WebSocket capacity, database capacity, or production availability. A representative M6 benchmark still needs authenticated location updates, concurrent trip creation and matching, sustained duration, resource measurements, and a named staging environment.
